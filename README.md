# VK-бот: настройка сообщества

VK-бот работает в **сообществе** (группе), а не от личной страницы. База общая
с Telegram-ботом — можно запускать оба одновременно.

## 1. Создать сообщество
vk.com → Сообщества → Создать сообщество (любой тип, например «Бизнес»).

## 2. Включить сообщения
Управление → Сообщения → **Сообщения сообщества: включены**.

## 3. Включить возможности ботов
Управление → Сообщения → Настройки для бота →
- **Возможности ботов: включены**
- **Клавиатура для бота: включена** (иначе кнопок не будет)

## 4. Получить ключ доступа (токен)
Управление → Работа с API → Ключи доступа → Создать ключ.
Отметить права: **Управление сообществом** и **Сообщения сообщества**.
Скопировать длинную строку — это `VK_TOKEN`.

## 5. Включить Long Poll
Управление → Работа с API → Long Poll API →
- **Long Poll API: включён**
- Версия API: **5.131**

Вкладка «Типы событий» → включить:
- **Входящее сообщение** (message_new)
- **Событие с кнопки** (message_event)
- **Вступление в сообщество** (group_join) — без этого пункта авторегистрация подписчиков не будет работать

Без второго пункта инлайн-кнопки не будут работать.

## 6. Узнать ID сообщества
Управление → Работа с API → там же виден ID. Либо из адреса `vk.com/club123456789`
взять цифры. Это `VK_GROUP_ID` (только цифры, без «club»).

## 7. Узнать свой VK ID (педагога)
Открыть свою страницу → если адрес вида `vk.com/id12345`, то ID = 12345.
Если задан короткий адрес — посмотреть через любой сервис «узнать id вконтакте»
или в мобильном приложении: Настройки → Аккаунт.
Это `VK_ADMIN_ID`.

## 8. Запуск

```bash
pip install -r requirements.txt

export VK_TOKEN="ключ_доступа_сообщества"
export VK_GROUP_ID="123456789"
export VK_ADMIN_ID="12345"
python vk_bot.py
```

## Несколько админов сразу

`VK_ADMIN_ID` теперь может содержать несколько ID через запятую — например,
и твой, и её. Тогда управлять ботом (отмечать занятия, обновлять расписание,
добавлять учеников) сможете оба, каждый под своим VK-аккаунтом. Уведомления
о новых анкетах приходят всем указанным сразу.

```bash
export VK_ADMIN_ID="420380178,111222333"
```

Если оставить один ID (как раньше) — всё работает точно так же, это не
обязательное изменение.

## Как ученик привязывается

**Автоматически, через анкету.** Как только человек пишет боту первое сообщение
(или подписывается на сообщество и у него разрешены входящие сообщения от
сообществ), бот спрашивает: «Для кого занятия — Ребёнок или Взрослый?», а
дальше собирает контактные данные (ФИО, дата рождения, телефон, канал связи,
плюс ФИО родителя для детей). После заполнения анкеты тебе приходит полное
уведомление со всеми данными и кнопкой «💰 Задать занятия» — жмёшь и сразу
вводишь число.

**Вручную (как раньше)** — если хочешь завести кого-то до того, как он сам
напишет: жмёшь «➕ Новый ученик» в меню педагога, вводишь имя и число занятий,
бот выдаёт ссылку вида `vk.me/club123456789?ref=КОД`. Такой ученик анкету не
проходит — запись создаётся сразу с тем, что ты ввёл.

## Стоимость и расписание

Кнопка «💵 Стоимость» отдаёт прайс-лист текстом (задан в коде, в константе
`PRICE_TEXT` в `vk_bot.py` — если цены изменятся, править только там).

Кнопка «🗓 Расписание» отдаёт картинку с расписанием — её нужно один раз
загрузить. В меню педагога жми «📤 Обновить расписание» и следующим сообщением
пришли фото (именно как картинку, не файлом) — бот сохранит его и будет
отдавать всем, кто нажмёт «Расписание». Пока фото не загружено, ученики видят
вежливое «расписание скоро будет».

## Депозит

Если ученик не забрал сдачу, в меню педагога есть кнопка «🏦 Депозит» —
выбираешь ученика, вводишь сумму, она сохраняется на его карточке. Это просто
число в базе, без своей истории операций (в отличие от баланса занятий) —
удобно, чтобы не забыть, сколько человеку осталось вернуть.

## Напоминания ученикам

Когда у ученика после отметки занятия остаётся 1 занятие или занятия
заканчиваются совсем — ему лично (не только тебе) приходит сообщение с
призывом продлить абонемент. Работает только если у ученика есть привязка к
боту (прошёл анкету или привязался по ссылке).

## Группы учеников

В меню педагога — кнопка «👥 Группы»: там можно создать группу (например,
«Вт/Чт дети» или «Индивидуальные»), переименовать или удалить (удаление —
мягкое, ученики и история посещений не пропадают).

Один ученик может состоять сразу в нескольких группах. Состав группы
редактируется прямо там же, кнопкой «👥 Состав группы» — открывается список
всех учеников с галочками, нажатие сразу добавляет/убирает ученика из этой
группы. Отдельная кнопка в главном меню «👥 Назначить группы» делает то же
самое, но со стороны одного ученика — удобно сразу после его добавления
(бот сам предложит это после создания ученика или анкеты, если хотя бы одна
группа уже создана).

Кнопка «📋 Список» теперь показывает учеников блоками по группам, плюс блок
«Без группы» для тех, кого никуда не добавили.

Кнопка «✅ Занятие» тоже стала группо-зависимой: если группы созданы, бот
сначала спросит, по какой группе отмечаем (или «Все ученики» / «Без группы»),
и покажет чек-лист только по нужным людям — так гораздо быстрее отмечать
посещаемость, чем листать весь список студии. Если ни одной группы ещё не
создано, всё работает по-старому — общий список.

В самом чек-листе есть кнопка «☑️ Отметить всех» — в группе из десяти человек
обычно быстрее отметить всех и снять двоих отсутствующих. Когда отмечены все,
та же кнопка превращается в «☐ Снять всех».

Над кнопками всегда видно, по какой группе идёт отметка и сколько человек уже
отмечено («Занятие — Вт/Чт дети / Отмечено: 5 из 12») — при листании страниц
легко потерять счёт. После нажатия «Готово» в итоговом сообщении тоже указано,
по какой группе прошло занятие и сколько человек отмечено.

## Отчёт по посещаемости

Кнопка «📊 Отчёт» в меню педагога — за неделю, месяц или три месяца. Показывает,
сколько занятий проведено по каждой группе и сколько раз пришёл каждый ученик
(в самом низу — те, кто не был ни разу; им есть смысл написать).

Отчёт строится по истории посещений, и с этой версии каждое посещение
запоминает, по какой группе оно было отмечено. Занятия, отмеченные до
обновления, попадают в строку «Без группы» — это нормально, задним числом
их не восстановить.

## Если бот перезапустился

Незавершённые диалоги (анкета ученика, ввод суммы, начатая отметка занятия)
теперь сохраняются в базе и восстанавливаются при старте — раньше перезапуск
молча терял всё, и человек оставался висеть на середине анкеты. Диалоги,
брошенные больше суток назад, при старте удаляются.

Чтобы бот сам поднимался после падения, в проекте есть готовый systemd-юнит
`dance-vk-bot.service` — инструкция по установке в комментариях внутри файла.

## Напоминания о предстоящих занятиях (расписание с датами)

Это отдельная фича, которую ещё нужно спроектировать — прежде чем её делать,
нужно понять, как у вас вообще устроено расписание (у каждого ученика
фиксированный день/час или расписание общее на группу). Пока не реализовано.

## Оба бота сразу
Telegram и VK используют один файл базы `dance.db`. Запускать в двух окнах терминала:

```bash
python bot.py       # окно 1
python vk_bot.py    # окно 2
```

Отметил занятие в ВК — в телеграме у ученика сразу новый остаток.
